# 刷题程序

在终端练习 `.xls` 题库，支持顺序做题、随机抽题和错题回顾。原始脚本 `legacy/毛概V1.1.py` 的所有权归 @Platinum（XueJingyuan）所有，后续由 @CambridgeZ 重构和维护。

## 开始使用

需要 Python 3.10 或更新版本。在仓库根目录安装依赖并启动：

```shell
python -m pip install -r requirements.txt
python -m practice_problems
```

原命令 `python 刷题程序重构版.py` 仍然可用，不需要安装 pandas 或 xlwt。

| 菜单 | 功能 |
| --- | --- |
| `0` | 按工作表顺序做题，记录答错的题号；暂停后从未答的那道题继续。做完本轮后返回菜单，下次从第一题开始。 |
| `1` | 随机抽题，一轮内不重复，不改变错题或顺序进度；输入一个空格跳过当前题。 |
| `2` | 按记录顺序回顾错题，保留重复记录；题号不在当前题库时提示并略过，不改变记录或顺序进度。 |
| `3` | 输入 `yes` 确认清空错题记录，不影响顺序进度。 |
| `4` | 退出程序。 |

答题时输入选项字母，大小写和多选字母顺序均不影响判分；输入 `?` 查看正确选项的数量。直接回车后输入 `1` 可暂停并回到菜单。顺序进度只在确认暂停或做完本轮时保存；顺序模式下的错题会立即写入。

## 题库和记录

默认使用当前目录中的三个文件。更换题库时，建议把新题库命名为 `题库.xls` 并放在单独的目录，避免沿用另一套题库的进度和错题：

```shell
python -m practice_problems --data-dir /path/to/quiz
```

- **`题库.xls`**：读取第一个工作表；第一行为表头，前十列依次为 `目录 | 题号 | 章节 | 题干 | A项 | B项 | C项 | D项 | 答案 | 类型`。题号须为唯一的正整数，答案须是非空选项的字母（如 `A`、`AC`）；选项不足四个时，其余单元格留空。
- **`lastFinish.txt`**：保存下次顺序做题时要显示的题号。缺失、空白或 `0` 都表示从头开始。
- **`错题记录.txt`**：每行一个错题题号。缺失或空白表示尚无错题。

旧版 `.txt` 记录可直接使用，无需转换。想用仓库附带题库从头开始，又不想修改原有记录，只需把 `题库.xls` 复制到一个新目录，再用 `--data-dir` 指向该目录。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `practice_problems/cli.py` | 菜单、三种模式的选题规则和记录更新时机 |
| `practice_problems/session.py` | 共用的答题交互、计时和正确率统计 |
| `practice_problems/question.py` | 题目模型、选项打乱及答案映射 |
| `practice_problems/bank.py` | 读取并校验 `.xls` 题库 |
| `practice_problems/records.py` | 读写顺序进度和错题文本 |
| `legacy/` | 原作者脚本、旧版错题 Excel 和题库备份，仅归档，主程序不依赖 |

新版不再维护旧的错题 `.xls` 副本，也不再支持未公开的 `+1` 加分指令。正确率按每道题正确选项的个数加权。

运行回归测试：`python -m unittest discover -s tests -v`。
